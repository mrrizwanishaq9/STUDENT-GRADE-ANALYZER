# STUDENT-GRADE-ANALYZER

Student Grade Analyzer is a Python-based educational project designed to calculate and analyze a student's academic performance. The program takes the student's name, roll number, and marks obtained in English, Mathematics, and Science as input.

It automatically calculates the total marks and percentage based on the three subjects. After calculating the percentage, the program assigns a grade according to predefined grading criteria. Grades range from A to E, where A represents excellent performance and E represents the lowest grade.

The program also determines whether the student has passed or failed based on the percentage. Finally, it displays a well-organized student result containing the student's name, roll number, individual subject marks, total marks, percentage, grade, and final result.

This project is useful for beginners who are learning Python programming and want to understand important programming concepts such as user input, variables, arithmetic calculations, conditional statements, if-elif-else structures, and formatted output.

## Features

* Student name and roll number input
* Marks input for English, Mathematics, and Science
* Automatic calculation of total marks
* Automatic percentage calculation
* Automatic grade assignment
* Pass/Fail result determination
* Organized result card
* Simple and beginner-friendly Python code

## Technologies Used

* Python
* Variables
* User Input
* Arithmetic Operators
* Conditional Statements
* If-Else Logic
* Basic Data Processing

## Grading System

* 90% or above → Grade A
* 75% to 89% → Grade B
* 60% to 74% → Grade C
* 45% to 59% → Grade D
* Below 45% → Grade E

The project provides a simple foundation for building more advanced student management and result management systems in Python.
